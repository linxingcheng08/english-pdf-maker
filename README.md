# 英熟語プリントサイト

`index.html` をブラウザで開くか、Netlify / GitHub Pages / Cloudflare Pages などに3ファイルまとめてアップロードすると公開できます。サーバーやデータベースは不要です。

## 使い方

- 「印刷 / PDF保存」からブラウザの印刷画面を開き、保存先で **PDFに保存** を選びます。
- 販売を始めるときは、`data.js` の `shopUrl` にBASE・BOOTH・Shopify等の商品ページURLを入れます。
- Google AdSenseの審査後、`data.js` の `adsenseClient` と `adsenseSlot` に発行された値を入れると、ページ下部の広告枠に広告を表示できます。PDF・印刷には広告は入りません。
- リストを増やすときは `data.js` の `SITE_DATA` に `{no: 番号, en: "英熟語", ja: "意味"}` を追加します。番号は連番にしてください。

## 公開前の確認

このサイトには運営者が公開権限を持つデータだけを掲載してください。市販教材や第三者の著作物を基にしたリストは、公開・販売に必要な許諾を事前に確認してください。

広告を表示する場合は、公開前にプライバシーポリシー、Cookie・広告配信に関する説明、必要な同意取得を用意してください。各広告サービスの最新ポリシーに従ってください。
